# Contributing

Matter for Threads is built with Theos for arm64 (`iphoneos-arm`). See the [README build instructions](README.md#building) for the release build command and required flags.

Keep changes focused and consistent with the existing Objective-C/Logos style. Keep runtime hooks signature-checked and fail-open when practical. Compatibility changes should include runtime evidence when available.

Do not submit Threads or Meta binaries, decrypted app files, proprietary assets, personal device logs, account/session data, or signing material. Privacy-sensitive logs must not include user content, usernames, user or post IDs, tokens, credentials, or filesystem paths.
